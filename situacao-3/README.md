## Verificação (testes automatizados)
O projeto contém sete cenários automatizados com pytest em `todo-app/tests/test_app.py`: criar, listar, editar, concluir, excluir, validar o título obrigatório e tratar erro 404. Para executar, consulte o [README do código](../todo-app/README.md).
